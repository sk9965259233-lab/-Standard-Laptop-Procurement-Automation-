# Project Overview

**Project:** Standard Laptop Procurement Automation

**Platform:** ServiceNow

**Main Tool:** Flow Designer

## Business Problem
IT hardware requests can require manual creation and assignment of tasks after approval. This can cause delays and inconsistent processing.

## Proposed Solution
Use ServiceNow Flow Designer to automatically create a Catalog Task when a Standard Laptop request is approved and route the task to the Hardware team.

## Benefits
- Less manual work
- Faster processing
- Consistent task assignment
- Better task visibility
- Fewer manual errors
